| Cột | Kiểu dữ liệu | Ràng buộc | Mô tả |
|---|---|---|---|
| id | INT | PK, AUTO_INCREMENT | Mã định danh user [cite: 4, 5] |
| username | VARCHAR(100) | NOT NULL | Tên hiển thị [cite: 5] |
| email | VARCHAR(150) | NOT NULL, UNIQUE | Email đăng nhập, không trùng [cite: 6] |
| password | VARCHAR(255) | NOT NULL | Mật khẩu đã hash [cite: 6, 7] |
| xp | INT | DEFAULT 0 | Điểm kinh nghiệm tích lũy [cite: 7, 8] |

| Nội dung | Chi tiết |
|---|---|
| Quan hệ đến bảng khác | 1-n với user_progress, quiz_results, user_badges [cite: 9, 10] |
| Hành vi xóa | Bị xóa sẽ xóa dữ liệu phụ thuộc (CASCADE) [cite: 10, 11] |
| Truy vấn phổ biến | Đăng ký, đăng nhập, cập nhật XP, lấy profile [cite: 11, 12] |

| id | INT | PK, AUTO_INCREMENT | Mã từ vựng [cite: 22] |

| created_at | TIMESTAMP | DEFAULT CURRENT_TIMESTAMP | Thời điểm tạo [cite: 27, 28] |

| Nội dung | Chi tiết |

4) BẢNG user_progress

Vai trò: Bảng liên kết users-words để theo dõi trạng thái học. [cite: 32]

| Cột | Kiểu dữ liệu | Ràng buộc | Mô tả |
|---|---|---|---|
| id | INT | PK, AUTO_INCREMENT | Mã bản ghi tiến trình [cite: 33, 34] |
| user_id | INT | NOT NULL, FK -> users(id) | Người học [cite: 34] |
| word_id | INT | NOT NULL, FK -> words(id) | Từ đang học/đã học [cite: 35] |
| status | ENUM('learning','learned') | DEFAULT 'learning' | Trạng thái học [cite: 35, 36] |
| learned_at | TIMESTAMP | DEFAULT CURRENT_TIMESTAMP | Thời điểm cập nhật [cite: 36, 37] |

| Nội dung | Chi tiết |
|---|---|
| UNIQUE | (user_id, word_id) để không trùng cặp user-từ [cite: 37, 38] |
| Quan hệ đến bảng khác | n-1 với users, n-1 với words [cite: 38, 39] |
| Truy vấn phổ biến | Upsert tiến trình, đếm số từ đã học theo user/topic [cite: 39, 40] |
-------------------------------------------------- [cite: 40]

III. BẢNG QUAN HỆ TỔNG HỢP
| Bảng cha | Kiểu quan hệ | Bảng con | Khóa liên kết | Xóa dây chuyền |
|---|---|---|---|---|
| topics | 1-n | words | words.topic_id -> topics.id | Có (CASCADE) [cite: 66, 67] |
| users | 1-n | user_progress | user_progress.user_id -> users.id | Có (CASCADE) [cite: 67, 68] |
| words | 1-n | user_progress | user_progress.word_id -> words.id | Có (CASCADE) [cite: 68, 69] |
| users | 1-n | quiz_results | quiz_results.user_id -> users.id | Có (CASCADE) [cite: 69] |
| topics | 1-n | quiz_results | quiz_results.topic_id -> topics.id | Có (CASCADE) [cite: 69, 70] |
| users | 1-n | user_badges | user_badges.user_id -> users.id | Có (CASCADE) [cite: 70, 71] |
| badges | 1-n | user_badges | user_badges.badge_id -> badges.id | Có (CASCADE) [cite: 71, 72] |
